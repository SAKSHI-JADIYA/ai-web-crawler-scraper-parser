# 🕸️ AI Web Scraper  

An AI-powered tool for extracting and structuring data from websites.  

## 🛠️ Tech Stack  
- **Python**  
- **BeautifulSoup / Requests** – for scraping and parsing HTML  
- **OpenAI / LLM integration** – for intelligent content detection  
- **Pandas** – for cleaning and structuring data  
- **Optional: Playwright/Selenium** – for handling JavaScript-heavy sites  

## ⚙️ How It Works  
1. **Load webpage** – Fetches the target site using `requests`.  
2. **Parse content** – Uses BeautifulSoup to extract raw HTML elements.  
3. **AI filtering** – LLM identifies relevant text, links, or structured data.  
4. **Data cleaning** – Removes noise and formats output.  
5. **Export** – Saves results in JSON or CSV for easy use.
